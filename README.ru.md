# Milliy-ed (EduAdapt)

**Адаптивная образовательная платформа с использованием ИИ — единая среда для учителя, ученика, родителя и администрации школы.**

🇺🇿 [O'zbekcha](README.md) · 🇷🇺 **Русский** · 🇬🇧 [English](README.en.md)

---

## Проблема

В школе один учитель даёт одинаковый материал 30+ ученикам. Вовремя заметить,
кто отстаёт, сложно, а родители часто узнают об успеваемости ребёнка только в
конце четверти.

## Решение

EduAdapt отслеживает уровень каждого ученика в реальном времени и подстраивает
вопросы под него. ИИ помогает учителю, но **никогда его не заменяет** — итоговую
оценку всегда ставит учитель.

## Основные возможности

| Модуль | Что делает |
|---|---|
| **Адаптивный тест** | После верного ответа вопрос усложняется, после ошибки — упрощается |
| **Создание контента с ИИ** | Учитель вводит тему — ИИ предлагает упражнение |
| **Оценивание с участием человека** | ИИ предлагает балл, учитель подтверждает или правит |
| **Раннее предупреждение** | Ученик с уровнем ниже 45% отмечается автоматически |
| **Посещаемость и связь с родителями** | Ежедневная посещаемость и прямая переписка с учителем |
| **Обучение на дому** | Индивидуальный план и адаптации для тех, кто не может посещать школу |
| **Центр вовлечения** | Мобильная лаборатория и наставники для отдалённых районов |
| **Повышение квалификации** | Международные курсы и знаки отличия для учителей |
| **Панель администратора** | Сводные показатели по школе или району |

## Безопасность

Система работает с данными детей, поэтому безопасность проработана отдельно:

- **У каждого ученика свой аккаунт.** Учитель выдаёт одноразовый код, ученик сам
  создаёт пароль. Войти под чужим именем невозможно.
- **Все пароли хешируются bcrypt** и никогда не передаются в браузер.
- **Ответы на тесты остаются на сервере** — в браузер уходят только вопрос и
  варианты, проверку выполняет сервер.
- **Уровень знаний рассчитывается на сервере** — клиент не может поставить себе оценку.
- **Родитель видит только своего ребёнка** (отдельный код для каждой семьи).
- **Ключ ИИ хранится только на сервере**, с ограничением запросов на пользователя.
- **Автоматическое резервное копирование** каждые 24 часа, хранится 14 дней.

## Технологии

**Frontend:** React 18, Vite, Tailwind CSS, Recharts
**Backend:** Node.js, Express, SQLite, JWT, bcrypt
**ИИ:** Anthropic Claude API (через серверный прокси)

## Структура проекта

```
src/                 React frontend
  lib/api.js         связь с backend
  views/             экраны по ролям
server/              Express backend
  src/db.js          схема SQLite
  src/auth.js        JWT и проверка ролей
  src/routes/        API endpoints
  src/backup.js      автоматические бэкапы
```

## Запуск

```bash
# Backend
cd server
cp .env.example .env      # заполните JWT_SECRET и ADMIN_PASSWORD
npm install
npm run dev               # http://localhost:8787

# Frontend (во втором терминале)
cp .env.example .env
npm install
npm run dev               # http://localhost:5173
```

Для `JWT_SECRET`: `openssl rand -hex 32`

Для функций ИИ добавьте `ANTHROPIC_API_KEY` в `server/.env`. Всё остальное
работает и без ключа.

## Как входит каждая роль

| Роль | Что нужно |
|---|---|
| Учитель | Код класса + пароль класса |
| Ученик (впервые) | Код класса + имя + одноразовый код, затем создаёт свой пароль |
| Ученик (далее) | Код класса + имя + свой пароль |
| Родитель | Код класса + имя ребёнка + родительский код |
| Администратор | Имя + пароль администратора |

Одноразовый код удаляется после использования. Если ученик забыл пароль, учитель
выдаёт новый код кнопкой «Сбросить пароль».

## Резервное копирование и экспорт

Сервер сохраняет копию в `server/data/backups/` при запуске и каждые 24 часа,
храня последние 14. Учитель может выгрузить три CSV-файла: список с кодами
доступа, оценки и посещаемость. Файлы корректно открываются в Excel.
